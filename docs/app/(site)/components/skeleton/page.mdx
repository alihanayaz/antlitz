# Skeleton

A placeholder for content that has not loaded.

```tsx
import { Skeleton } from "antlitz";
```

## API

<PropsTable component="Skeleton" />

It is `aria-hidden`, so assistive technology skips it entirely. Announce the
loading state with a live region or a `Spinner` if the wait is long enough to
need one.

## Usage

<Preview file="skeleton" name="Loading" />

Skeleton is a full-width pulsing block with no height of its own. Give it the
shape of the content it stands in for.
