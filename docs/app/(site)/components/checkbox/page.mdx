# Checkbox

A binary choice. Renders a native checkbox with `appearance: none`, so keyboard
handling, form submission, and the `indeterminate` state come from the
platform.

```tsx
import { Checkbox } from "antlitz";
```

## API

<PropsTable component="Checkbox" />

`indeterminate` has no HTML attribute — it is a DOM property — so the component
sets it on the element through a ref.
