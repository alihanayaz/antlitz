# Textarea

A multi-line text field. Shares Input's variants, sizes and states, and grows
with its content by default.

```tsx
import { Textarea } from "antlitz";
```

## API

<PropsTable component="Textarea" />

Unlike `Input`, `textarea` has no native `size` attribute, so nothing is
omitted from the underlying element's props.

## Sizing

<Preview file="textarea" name="Sizing" layout="grid" />

`field-sizing-content` is applied by default, so the box grows as the user
types and no resize handle is needed. To pin it, set `rows` and override with
`field-sizing-fixed`.
