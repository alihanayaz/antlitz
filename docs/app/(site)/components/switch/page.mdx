# Switch

Toggles a setting that takes effect immediately. Renders a native checkbox with
`role="switch"`, so keyboard and form behaviour come from the platform.

```tsx
import { Switch } from "antlitz";
```

## API

<PropsTable component="Switch" />

Because it is a checkbox underneath, every `input` attribute applies: `checked`,
`defaultChecked`, `disabled`, `name`, `onChange`.

## Usage

<Preview file="switch" name="Basic" />

Pair it with a `Label` or a `Field` — the switch renders no text, and an
unlabelled toggle is not usable with a screen reader.
