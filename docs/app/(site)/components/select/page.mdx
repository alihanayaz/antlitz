# Select

A single choice from a list. Renders a native `select`, so the option list is
the platform's — correct on touch devices and with a screen reader, at the cost
of not being stylable.

```tsx
import { Select } from "antlitz";
```

<PropsTable component="Select" />

Like `Input`, the native `size` attribute is removed from the type so it cannot
collide with the variant prop.
