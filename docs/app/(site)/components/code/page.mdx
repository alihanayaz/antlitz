## Sizes

<Preview file="code" name="Sizes" />

Size sets padding. The text size is `0.875em`, relative to whatever contains
it, so a fragment stays proportional to the sentence it sits in rather than
snapping to a fixed scale.

## Prose

Code is for interface text — a table cell, a label, a caption. Inside content
rendered with the Typeset stylesheet, a plain `code` element is already styled
and no component is needed.
