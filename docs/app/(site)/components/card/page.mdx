```tsx

```

## Interactive

<Preview file="card" name="Interactive" />

`interactive` adds hover and focus affordances for cards that behave as a
single target. Pair it with `asChild` and a link so the whole card is one
control, rather than nesting a link inside a clickable div.

## Composition

<Preview file="card" name="Composition" />

Card is a flex column with `overflow-hidden`, so a rounded card clips its
children. It sets no gap — spacing between children is the caller's decision.

The border belongs to the `outline` variant rather than the base: a transparent
border on every variant would inset content by 1px in variants that show no
border, because normal-flow children lay out in the content box.
