# antlitz

A minimal React and Tailwind design system. Native elements, semantic tokens,
no behavioural dependencies.

## Installation

```sh
pnpm dlx antlitz init
```

`init` installs the package, adds Tailwind CSS v4 if the project has no v4
yet, and writes the imports into your global stylesheet — creating it, and a
PostCSS config, when they are missing. It detects the package manager from the
lockfile.

To do it by hand instead:

```sh
pnpm add antlitz
```

```css
@import "tailwindcss";
@import "antlitz/theme.css";
```

## Usage

Every component is a plain export from the package root.

```tsx
import { Button } from "antlitz";
```

For long-form content rendered from data — markdown, MDX, a CMS field — import
the Typeset stylesheet and wrap the output.

```css
@import "antlitz/typeset.css";
```

Colours come from named tokens rather than a palette, so restyling the system
is a matter of redefining them. See Theme.
